**4. Write a program that calls fork() and then calls some form of exec() to run the program /bin/ls. See if you can try all of the variants of exec(), including (on Linux) execl(), execle(), execlp(), execv(), execvp(), and execvpe(). Why do you think there are so many variants of the same basic call?**

The different exec() variants provide flexibility in how the program path, command-line arguments, and environment variables are supplied, and whether the PATH environment variable is used to locate the executable.
